# 🛒 E-commerce Sales Data Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data using SQL to extract meaningful business insights related to revenue, products, customer behavior, and regional sales performance.

---

## 🛠️ Tools Used

* SQL
* MySQL Workbench

---

## 📂 Dataset Information

The dataset contains:

* Order IDs
* Product names
* Quantity sold
* Invoice dates
* Unit prices
* Customer IDs
* Country information

---

## 📊 Analysis Performed

* Total Revenue Calculation
* Top 5 Products by Revenue
* Top 5 Countries by Revenue
* Monthly Revenue Trend Analysis
* Total Number of Orders

---

## 📈 Key Insights

* Identified top-performing products contributing maximum revenue
* Analyzed country-wise sales performance
* Explored customer purchasing activity
* Evaluated overall business sales trends
